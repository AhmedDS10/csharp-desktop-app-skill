## 1) تفعيل النسخة المحدّثة
- المهارة مرتبطة بالمجلد `csharp-desktop-app` الذي يحتوي `SKILL.md` ومجلد `references/`. استبدل المجلد القديم بمحتوى `csharp-desktop-app.zip` أينما كانت المهارة مثبّتة عندك.
- إن كنت ترفع المهارات من إعدادات Claude، ارفع الـ zip نفسه كمهارة جديدة بنفس الاسم. لا أعرف مسار القائمة بالضبط في واجهتك، فابحث عن قسم المهارات (Skills) في الإعدادات.

## 2) تشغيلها
اكتب `/csharp-desktop-app` ثم وصف التطبيق. مثلاً:

```
/csharp-desktop-app تطبيق WPF لإدارة المخزون: أصناف وكميات وبحث، واجهة عربية، مع مثبّت
```

التفاصيل التي تؤثر على النتيجة:
- **الإطار:** اذكر WPF أو WinForms. إن لم تذكر، يختار WPF ويقول ذلك.
- **اللغة:** اكتب طلبك بالعربية فتُضبط الواجهة على RTL تلقائياً.
- **التخصيص:** قل "بدون اختبارات" أو "بدون مثبّت" أو "بدون ثيمات" فيحذف الجزء المطلوب.
- **SQLite:** اطلبها صراحة إن أردت قاعدة بيانات بدل ملف JSON.

## 3) بعد توليد المشروع
شغّلها من مجلد الحل على ويندوز مع .NET 8 SDK:

| الهدف | الأمر |
|---|---|
| تشغيل التطبيق | `dotnet run --project AppName` |
| الاختبارات | `dotnet test` |
| ملف exe واحد في `publish/` | `./publish.ps1` |
| نسخة أصغر تحتاج .NET Runtime | `./publish.ps1 -FrameworkDependent` |
| مثبّت Setup.exe | `iscc installer.iss` بعد النشر، ويحتاج Inno Setup |

أماكن الملفات على جهاز المستخدم:
- البيانات والإعدادات: `%AppData%\AppName\data.json` و`settings.json`
- السجلات: `%AppData%\AppName\logs\`

## 4) ملاحظة مهمة
لم أتمكن من بناء الكود أو اختباره عندي، فأول تشغيل عندك هو الاختبار الفعلي. إن ظهر خطأ في البناء، أرسل لي نصه وأصلحه في المهارة نفسها حتى لا يتكرر في المشاريع القادمة.
